  • התלמידים מפרקים מוצר לצורות בסיסיות (קופסה, גליל, חרוט, גג, כדור וצורת חור) ומשרטטים פירוק עם מידות לפני שהם בונים.

הכנה לפני השיעור

שבוע לפני

  • חשבון מחנך ב־Tinkercad: tinkercad.com ← Sign Up ← "Educators start here" ← "Continue as an educator". ממלאים את ההצהרה ומתחברים מחשבון העבודה.
  • כיתה: Classes ← Create new class ← שם: "יזמות · [בית הספר] · [כיתה]". Safe Mode פעיל כברירת מחדל ונשאר כך.
  • מושבים לתלמידים: בתוך הכיתה: Students ← Add students. לכל תלמיד/ה Name (שם פרטי ואות, למשל "נועה ב") ו־Student login: כינוי של 3–20 תווים, למשל tiger7 או team3a. כמה בבת אחת: Add in bulk. שומרים לעצמכם רשימה: איזה כינוי של מי.
  • פתקי כניסה: בכיתה ← Class roster ← הדפסה. גוזרים פתק לכל תלמיד/ה. את קוד הכיתה (9 תווים) מעתיקים, ובשיעור מקלידים אותו בשקף 6 (התיבה "קוד הכיתה" זוכרת אותו בדפדפן שלכם).
  • לבקש מהמורה המלווה לבדוק שיש מחשבים או כרומבוקים עם עכבר (סיבוב דגם עם משטח מגע מתסכל), ושהאתר tinkercad.com לא חסום ברשת.

יום לפני (חזרה גנרלית, 30 דקות)

  • לבנות בעצמכם את הספל מדגם הבזק (שקף 16) ואת "קופסת הפסקה" (המתכון בסעיף "כלים"). מצלמים מסך של כל אחד לגיבוי.
  • להריץ את כל הפרומפטים (סעיף "פרומפטים") ב־Gemini, כולל "מהנדס/ת ייצור" עם צילום מסך של הקופסה, ולצלם את התשובות לגיבוי.
  • צילום קטלוג מהמסך שלכם: בחשבון העבודה, מעלים את צילום המסך של הקופסה ל־Gemini ומבקשים צילום מוצר ריאליסטי. שומרים את התמונה. זה רגע ה"וואו" של שקף 30, ובשיעור אפשר לעשות את זה על המקרן לצוות אחד או שניים.
  • טופס "הגשת תוצר" ב־Google Forms (אם עוד אין לקורס): forms.google.com ← טופס ריק ← שם: "הגשת תוצר · שיעור 18". שאלות:
    1. שם הצוות (תפריט נפתח, חובה)
    2. קו הייצור (שאלה אמריקאית: A · המוצר עצמו / B · מה שעוטף / C · קרטון)
    3. קישור לשקף תיק הייצור ביומן (תשובה קצרה)
    4. 3 מידות במ״מ: אורך × רוחב × גובה (תשובה קצרה)

    6. "בעקבות ___ שינינו ___" (פסקה)
    7. הערכה עצמית במחוון, 1–4 לכל קריטריון (רשת)
    8. שורת AI: מה ה־AI עשה · מה אנחנו עשינו (פסקה)
    הגדרות ← תגובות ← לוודא ש"איסוף כתובות אימייל" כבוי. ואז "פרסום" ← "פרסום הטופס" (טופס שלא פורסם לא מקבל תשובות). "שיתוף" ← "העתקת הקישור של המשיב או המשיבה" ← "קיצור כתובת URL". מדביקים את הקישור הקצר בשקף 32.
  • יומן הסטארט־אפ: בכל יומן צוות (Google Slides משותף מהשיעורים הקודמים) מוסיפים שקף ריק "שיעור 18 · תיק ייצור". אם אין יומנים, הצוות יוצר מצגת חדשה: slides.google.com ← מצגת ריקה ← משתף/ת איתכם.
